# Falling Sand Colony Towers

A browser-playable falling-sand colony tower game.

## Play

Once `index.html` is committed to the repository root and GitHub Pages is enabled, open the Pages site URL.

## Deploy

This repository includes a GitHub Actions workflow that publishes the repository root to GitHub Pages on pushes to `main`.

## Support the colony

Falling Sand Colony Towers is free to play. If you enjoy watching the colony grow, you can support new buildings, weather and creatures on **[GitHub Sponsors](https://github.com/sponsors/kefirman9000)**. Starring the repo helps too.
